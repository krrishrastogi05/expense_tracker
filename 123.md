Computer Networking Interview Prep — In the Right Order

0. First understand these 8 words

Before touching OSI, routers, VPNs, DNS, etc., know these.

Keyword	Simple meaning

Network	Devices connected so they can communicate
Node	Any device participating in a network
Link	Connection between two nodes
Protocol	Agreed rules for communication
Packet	A chunk of data sent through a network
Frame	A packet wrapped for delivery over a local link
Bandwidth	How much data can be transferred per second
Latency	How long data takes to travel


These words appear everywhere.

1. What is a computer network? ⭐⭐⭐

Interview answer

A computer network is a collection of interconnected devices that communicate and share data/resources using agreed communication protocols.

Devices may include:

computers

phones

servers

routers

printers

IoT devices


Example

Your home Wi-Fi is a network:

Laptop ─┐
Phone ──┼── Wi-Fi Router ─── Internet
TV ─────┘

Your devices communicate with the router, and the router connects your local network to other networks.

Important keyword: Protocol

A protocol is simply a set of communication rules.

Examples:

HTTP → web communication

TCP → reliable transport

IP → addressing/routing

DNS → domain-name resolution


Think:

> Humans need a common language. Computers need common protocols.

4. What is network topology? ⭐⭐

A network topology describes how devices and connections in a network are arranged.

Two ideas exist:

Physical topology

How devices/cables are physically connected.

Logical topology

How data logically flows through the network.

For basic interviews, "topology" usually means the arrangement of devices.


---

5. Types of network topology

Don't memorize paragraphs. Understand the pictures.


---

Bus topology

PC ─── PC ─── PC ─── PC
========================
       Main cable

All devices share a common backbone.

Advantage

Cheap/simple.

Problem

Failure of the backbone can affect the entire network.

Mostly historical today.


---

Star topology ⭐⭐⭐

PC
         |
PC ── Switch ── PC
         |
       Server

Every device connects to a central device, usually a switch.

Advantages

easy to manage

easy to troubleshoot

one cable failure usually affects only one device


Disadvantage

Central device failure can affect the network.

Important

Most modern Ethernet LANs effectively use star topology.


---

Ring topology

A ── B
|    |
D ── C

Each node connects to neighbouring nodes, forming a ring.

Not common in ordinary modern LANs.


---

Mesh topology

A ───── B
|\     /|
| \   / |
|  \ /  |
|  / \  |
| /   \ |
C ───── D

Nodes have multiple possible paths.

Advantage

Very resilient.

Disadvantage

Expensive and complicated.

Used conceptually in systems where redundancy is important.


---

Tree topology

Hierarchical combination of networks.

Core
        /      \
     Switch   Switch
     /  \      /  \
    A    B    C    D

Very common concept in larger enterprise networks.


---

Hybrid topology

Combination of different topology types.

Real networks are often effectively hybrid.

6. Now understand the OSI model ⭐⭐⭐⭐⭐

This is where your original notes went wrong.

You shouldn't hear "Data Link Layer" while having no idea what it means.

The OSI model divides networking into 7 conceptual layers.

Think of it as:

7 Application     What applications use
6 Presentation    Data representation
5 Session         Conversation/session management
4 Transport       Process-to-process delivery
3 Network         Device-to-device across networks
2 Data Link       Local network delivery
1 Physical        Actual signals/bits

Mnemonic:

> All People Seem To Need Data Processing



Application
Presentation
Session
Transport
Network
Data Link
Physical

7. Why do networking layers exist?

Suppose you open:

https://google.com

Many completely different problems must be solved.

For example:

What application protocol?
        ↓
How do we reliably send data?
        ↓
Which destination IP?
        ↓
Which local device receives the frame?
        ↓
How are electrical/radio signals transmitted?

Instead of designing one gigantic networking system, responsibilities are divided into layers.

That makes networks:

modular

easier to design

interoperable

easier to troubleshoot

9. OSI Layer 2 — Data Link Layer ⭐⭐⭐⭐⭐

Now we can finally talk properly about switches and bridges.

The Data Link Layer handles communication between devices over a local link/network.

Its data unit is called a:

> Frame



It commonly works with:

> MAC addresses



Example:

Laptop
MAC: AA:AA
   |
 Switch
   |
Printer
MAC: BB:BB

The switch learns which MAC address is on which port.

If Laptop sends a frame to BB:BB, the switch can forward it toward the printer.

Important Layer-2 concepts

Ethernet

MAC addresses

Frames

Switches

Bridges

error detection such as CRC

10. What is a MAC address? ⭐⭐⭐

A MAC address identifies a network interface at the Data Link Layer.

Example:

00:1A:2B:3C:4D:5E

A simplified comparison:

MAC address → local-network delivery
IP address  → delivery across networks

This distinction becomes extremely important for switch-vs-router questions.

12. What is an IPv4 address? ⭐⭐⭐⭐⭐

IPv4 identifies a device/interface for IP communication.

It contains:

> 32 bits



Usually written as four decimal numbers:

192.168.1.25

Each section contains 8 bits:

192 . 168 . 1 . 25
 ↓     ↓    ↓    ↓
8bit  8bit 8bit 8bit

Therefore:

4 × 8 = 32 bits

Each octet ranges from:

0 to 255

Correction to your source

IPv4 is not inherently a "dynamic address."

An IPv4 address may be assigned:

dynamically using DHCP

statically by configuration

13. IPv4 classes

You should know this for interviews because older interview questions still ask it.

Historically:

Class	First octet	Purpose

A	0–127	Very large networks
B	128–191	Medium networks
C	192–223	Smaller networks
D	224–239	Multicast
E	240–255	Reserved/experimental


But there are reserved values inside these ranges.

For example:

127.x.x.x

is reserved for loopback.

Important modern point ⭐

Classful addressing is largely obsolete.

Modern IP networks use:

> CIDR — Classless Inter-Domain Routing



For example:

192.168.1.0/24

An interviewer asking about IPv4 classes may expect the historical answer, but mentioning CIDR demonstrates stronger understanding.

Range

Simplified:

Laptop ─┐
Phone ──┼── Router/NAT ───── Web Server
TV ─────┘

This is extremely common in real networks.

18. TCP vs UDP ⭐⭐⭐⭐⭐

TCP

Transmission Control Protocol

Provides:

connection-oriented communication

reliable delivery

ordered delivery

retransmission of lost data

flow/congestion mechanisms


Examples commonly using TCP:

HTTP/1.1

HTTP/2

HTTPS

SSH

SMTP



---

UDP

User Datagram Protocol

Provides a simpler connectionless datagram service.

It does not itself guarantee:

delivery

ordering

retransmission


It has lower protocol overhead.

Used in applications such as:

DNS commonly

real-time media

gaming

DHCP


And modern HTTP/3 uses QUIC over UDP, which implements reliability and other features above UDP.


---

Interview comparison

TCP	UDP

Connection-oriented	Connectionless
Reliable byte stream	Datagram-based
Maintains ordering	Doesn't guarantee ordering
Retransmits when needed	No built-in retransmission
More protocol machinery	Simpler transport

A better interview answer than the original article:

Don't memorize this from the article:

> "OSI has low reliability; TCP/IP has high reliability."

24. Switch vs Bridge vs Router ⭐⭐⭐⭐⭐

Now this becomes easy because you understand layers.

Bridge

Usually Layer 2.

Connects LAN segments and makes forwarding decisions using MAC addresses.

Historically important.


---

Switch

Also normally Layer 2.

Essentially a highly capable multi-port bridge.

Uses a MAC-address table.

Example:

PC ──┐
PC ──┼── Switch
PC ──┘

Connects devices within a LAN.


---

Router

Layer 3.

Uses:

> IP addresses



and a:

> routing table



to move packets between IP networks.

Example:

Network A
192.168.1.x
     |
   Router
     |
Network B
10.0.0.x


---

Interview summary

Bridge → connects LAN segments → MAC → Layer 2

Switch → connects devices/segments → MAC → Layer 2

Router → connects IP networks → IP → Layer 3

Important

Modern Layer-3 switches can perform both switching and routing functions.

25. What is a gateway? ⭐⭐⭐

The original source's explanation is oversimplified.

A gateway is a node through which traffic leaves one network/domain to reach another.

In an ordinary LAN, your:

> default gateway



is usually your router.

Example:

Laptop
192.168.1.20
     |
     | Default gateway = 192.168.1.1
     ↓
   Router
     |
 Internet

A gateway can also refer more generally to systems that translate between different protocols or environments.

Don't say:

> "A router can only connect similar networks."



That's not generally correct.

Routers route IP traffic and can connect interfaces using different underlying link technologies.

30. What is ping? ⭐⭐⭐⭐⭐

ping helps test IP reachability and measure round-trip behaviour.

Example:

ping google.com

It typically uses:

> ICMP Echo Request



Destination replies with:

> ICMP Echo Reply



You might see:

Reply from ...
time=20 ms
TTL=117

Ping can tell you things such as:

whether ICMP responses are being received

approximate round-trip time

packet loss statistics


Important interview nuance

No ping response doesn't always mean the host is down.

A firewall/network policy may block ICMP echo while other services still work.

31. What is ICMP? ⭐⭐⭐

ICMP = Internet Control Message Protocol

Used for diagnostic/error/control messages in IP networking.

Examples include:

Echo Request
Echo Reply
Destination Unreachable
Time Exceeded

Tools such as ping and traceroute rely heavily on ICMP behaviour, depending on implementation.

Each router forwarding the packet decreases TTL.

TTL = 3
   ↓ router
TTL = 2
   ↓ router
TTL = 1
   ↓ router
TTL = 0 → packet discarded
